    表示と保存の設定

    画面に出す名前と、保存のしかたを決めます。

    見本 — このツールで作った資料は、あとから自分で読み返すためのものです。 const example = 1;

    反映範囲 この設定は現在のドキュメントに保存され、再読込後と配布 HTML にも引き継がれます。
    新しい版が出たら、お知らせしますか？ 起動時に版番号だけを読みます。書いた内容は送りません。 「いいえ」ならどこへも通信しません。あとから設定で変えられます。

    使い方

    最初に読むのは 1 と 2 だけで足ります。残りは必要になったときに開いてください。

    画面写真つきの詳しい手引きを開く →
    1書く

    本文をクリックすればそのまま書けます。保存のボタンはありません（打ち終わって少し経つと自動で保存されます）。

    ツールバーの「見出し」「段落」「Code」「表」で、書きたいものの形を足します。 Tab で一段下げ、Shift+Tab で戻せます。

    2畳む — 「セクション」と「引きだし」

    長くなってきたら セクション（大きな折りたたみ）で囲みます。畳んでおけば、 開いているものだけが目に入ります。

    引きだしは、その中でさらに小さく畳むためのものです。 「details」「調べたときのメモ」「あとで読む」のような、いま要らないが捨てたくないものを入れます。

    3あとで見返す — 「本日更新」

    画面のいちばん下に、その日に書き足した所だけが自動で集まります。 どこを触ったか思い出せなくても、ここを見れば足りるようになっています。

    「履歴」を押すと、過去の日付でも同じものが見られます。

    4並べ替えるときは「整理」を押してから

    移動や削除だけをしたいときは、ツールバーの 整理 を押してから作業します。 その間の変更は「本日更新」に出ません。

    これを使わずに大掃除をすると、その日の「本日更新」が移動した行で埋まって、 本当に書いたことが見えなくなります。

    5人に見せる — 「共有」

    共有を押すと、HTML が1ファイルだけ出てきます。相手はそれを開くだけで読めます。 インターネットに接続していなくても開けますし、どこかへ送信もされません。

    ここに書くのは「こう使うと楽です」という一例です。合わないと思ったら無視してください。 道具のほうを自分に合わせるほうが、続きます。

    迷ったら、この3層にする

    1. いま動いているもの … 開いたままのセクション。多くても3つまで。
    2. 止まっているもの … 畳んだセクション。いつでも開けるので、消さずに畳む。
    3. 終わったもの … いちばん下に「済」のセクションを1つ作り、そこへ落とす。

    消さずに下へ落としていくのが要点です。消すと履歴から消え、 「あのとき何をやめたか」が分からなくなります。

    付箋は「やること」ではなく「戻ってくる場所」に使う

    画面の右に貼れる付箋は、押すとその場所へ飛びます。 やることリストとして使うと増えすぎて効かなくなるので、 「今週ここに戻ってくる」という数枚に絞ると長持ちします。

    作業ファイルは「別の頭で考えるもの」ごとに分ける

    分ける基準は量ではなく頭の切り替えです。 仕事と趣味、制作と勉強のように、同時に考えたくないものを分けます。

    逆に、関係があるなら1つに入れたままにします。分けると、 「本日更新」も履歴も別々になり、行き来が面倒になります。

    週に一度だけ、「整理」を押して大掃除する

    毎日やる必要はありません。週に一度、整理を押した状態で、 終わったものを下へ落とし、畳めるものを畳みます。 このときの移動は「本日更新」に出ないので、その週に書いたことの記録は汚れません。

    書くのをやめる日があってよい

    何も書かなかった日は、「本日更新」に何も出ないだけです。 埋めなければいけない欄はどこにもありません。

    作業ファイルの整理

    名前を変えたり、使わなくなったものを片付けたりできます。

    片付けたものはどこへ行くか 消したように見えても、中身は _trash フォルダへ移すだけです。 書いたものが押し間違いで永久に消えることはありません。

    履歴を HTML で書き出す

    選んだ期間の「何が増えて何が減ったか」を、1ファイルの HTML にまとめます。

    読み方 各日付の下に、その日に増えた行（＋）と減った行（−）が並びます。ネット接続なしで読めます。

    付箋を追加

    ✓ 保存しました

    これは「ブラウザで試す版」です

    書いたものは、いま使っているこのブラウザの中だけに残ります。 機能は製品版とまったく同じものが動いています（同じプログラムです）。

    • 別のPCや別のブラウザからは開けません
    • 閲覧データを消すと、書いたものも消えます
    • 自動のバックアップはありません

    ずっと使うなら、PCに入れる版をどうぞ。保存先が自分のPCのフォルダになり、 ファイルとして残ります。
