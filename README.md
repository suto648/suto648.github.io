# 製品紹介ページ

`https://suto648.github.io/` として公開している1枚ページ。

- **やるべきこと-editor**（有料・Windows）の紹介と、使い方の全文
- **CbC Tools** と **Claude セッション盤面**（無料）への入口

## 作りの約束

- **外部のスクリプトとフォントを1つも読み込まない。** 紹介している製品自体が
  完全オフラインなので、紹介するページも同じ作りにしている。
- 画面写真は `img/`。**すべて作った見本データで撮ったもので、実際の作業内容は写っていない。**
- `guide/` は製品に同梱している「使い方」の写しで、**買う前に全文が読める**。
  体験版を作らない代わりの措置（`自律ループ/アプリ製品化/SALES-PLAN.md` §3）。

## 直すとき

`index.html` 1枚で完結している。`#buy` の中のボタンは、販売ページができたら
`href` と `aria-disabled` を差し替える。
